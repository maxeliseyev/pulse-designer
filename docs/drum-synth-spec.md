# Драм-синтезатор: спецификация

Инструментальный плагин. **Один инстанс — один инструмент — один звук.** Без секвенсора, без мультитембральности, без мультивыходов.

---

## 1. Принцип

Два источника — осциллятор и шум, — каждый со своей огибающей, смешиваются и проходят через насыщение. Этого достаточно для бочки, снейра, томов, хэта, клэпа и всей электронной перкуссии.

Решение «одна нота на инстанс» принято сознательно: оно убирает из проекта голосовую арифметику, разводку выходов, секвенсор и половину интерфейса. Многоканальность собирается в хосте дорожками, где ей и место.

## 2. Тракт

```
                 ┌─ Осциллятор ─ частотная огиб. ─ шейпер ─ огибающая A ─┐
MIDI note-on ───►│                                                        ├─ микс ─ drive ─ DC ─ tone ─ gain ─ pan ─ out
                 └─ Шум ─ фильтр ─ огиб. фильтра ─────────── огибающая B ─┘
```

Все параметры **защёлкиваются в момент note-on** и держатся до конца звучания голоса. Сглаживание параметров не требуется почти нигде, а звук получается повторяемым: одинаковая нота всегда даёт одинаковый результат.

## 3. Параметры

### Осциллятор

|---|---|---|---|
| Waveform | sine / triangle / square | sine | |
| Pitch | 20 Гц – 2 кГц, лог. | 55 Гц | базовая частота |
| Pitch Env Amount | −48…+48 полутонов | +36 | биполярный, вверх тоже нужен |
| Pitch Env Decay | 1–500 мс, лог. | 40 мс | |
| Pitch Env Curve | 0–1 | 0.8 | линейная ↔ экспоненциальная |
| Start Phase | 0–360° | 90° | характер атаки |
| Amp Attack | 0–50 мс | 0 | ноль допустим |

|---|---|---|---|
| Type | white / pink / metallic / S&H | white | metallic — банк негармоничных прямоугольников, как в 808 |

| Filter Env Decay | 1–500 мс, лог. | 60 мс | |

### Микс и выход

| Параметр | Диапазон | По умолчанию |
|---|---|---|
| Mix | осциллятор ↔ шум | 0.5 |
| Drive Type | soft / hard / asymmetric / fold | soft |
| Drive | 0–1 | 0 |
| Tone | −1…+1 | 0; к +1 ярче, ±6 дБ вокруг 1 кГц |
| Gain | −∞…+12 дБ | 0 дБ; −96 дБ и ниже — тишина |
| Pan | −1…+1 | 0, equal-power |

### Игра

| Параметр | Диапазон | По умолчанию |
|---|---|---|
| Vel → Level | 0–100% | 70% |
| Vel → Pitch Env | 0–100% | 20% |
| Vel → Cutoff | 0–100% | 0% |
| Vel Curve | 0–1 | 0.5 |
| Note Filter | omni / нота / диапазон | omni |
| Key Tracking | 0–100% | 0% |
| Voice Mode | restart / overlap | restart |
| Voices | 1–8 | 1 (при overlap) |

Пояснения:

- **Vel → Pitch Env** — при сильном ударе у настоящего барабана пластик натягивается и высота уходит выше. Небольшое значение сильно оживляет игру, поэтому не ноль по умолчанию.
- **Key Tracking** — позволяет играть инструмент хроматически с клавиатуры, оставаясь при этом ударным.
- **Voice Mode**: `restart` перезапускает единственный голос от текущего значения огибающей, `overlap` даёт хвостам накладываться. Для бочки нужен первый, для снейра с длинным хвостом и быстрой игры — второй.

## 4. Обязательные технические требования

Не пожелания, а условия того, что результат не будет звучать дёшево.

1. **Передискретизация 4× вокруг обоих шейперов** (`Shape` и `Drive`), переключаемая 1/2/4/8. Без неё насыщение низкого синуса даёт алиасинг, который слышен как пластиковый призвук. Оверсэмплится только нелинейный участок, не весь тракт.
2. **Блокировщик постоянной составляющей** на выходе, ФВЧ первого порядка на 10 Гц, всегда включён. Асимметричное искажение и короткие огибающие на низких частотах дают DC.
3. **Огибающие считаются посэмплово** и экспоненциально. Блочная аппроксимация слышна на затуханиях короче 50 мс.
4. **Перезапуск огибающей от текущего значения**, а не от нуля. Иначе щелчок на каждом быстром повторе.
5. **Сэмплово-точная обработка MIDI внутри блока.** События не выравниваются по границе буфера. На ударных дрожание в несколько миллисекунд слышно как расхлябанность.
6. **Фильтр — TPT/ZDF state variable** (`juce::dsp::StateVariableTPTFilter`). Устойчив при быстрой модуляции частоты, отдаёт LP/BP/HP одновременно, что и нужно для непрерывного морфа.
7. **`ScopedNoDenormals` в `processBlock`.** Экспоненциальные хвосты уходят в денормальные числа и роняют производительность.
8. **Независимость от частоты дискретизации.** Все времена в миллисекундах, частоты в герцах. На 44.1, 48, 96 и 192 кГц звук должен быть слышимо одинаковым.

## 5. Интерфейс

Одна панель, ничего не спрятано — параметров мало, и они все одного уровня важности. Два столбца (осциллятор / шум), снизу микс, drive и выход, сбоку секция игры.

Один визуальный элемент, который стоит усилий: **окно с формой волны результата**. При изменении любого параметра один удар рендерится офлайн и рисуется. Видно и форму атаки, и длину хвоста, и что сделал drive. Это и рабочий инструмент, и главный снимок экрана.

## 6. Пресеты

Небольшой заводской банк, каждый — рабочая точка отсчёта, а не демонстрация: kick deep, kick tight, snare, rim, tom, closed hat, open hat, clap, zap.

## 7. Чего в плагине нет

Записать явно, чтобы не расползалось: секвенсора, паттернов, нескольких голосов на инстанс, воспроизведения сэмплов, встроенных эффектов, MIDI-выхода, матрицы модуляций, LFO, choke-групп.

Choke-группы (закрытый хэт глушит открытый) потребовали бы обмена между инстансами — отдельная работа, возможна во второй версии.

## 8. Приёмочные тесты

- **Побитовая независимость от размера блока.** Один и тот же MIDI-поток при размерах буфера 32, 64, 512 и 2048 даёт идентичный выход. Ловит и блочную квантизацию MIDI, и ошибки в огибающих.
- **Проверка алиасинга.** Рендер на максимальном drive, анализ спектра: не должно быть заметной негармонической энергии ниже основного тона.
- **Проверка DC.** Среднее значение отрендеренного удара близко к нулю на всех пресетах.
- **Отсутствие щелчков при ретриггере** на интервалах от 5 мс.
- **Нагрузка** при восьми инстансах на дорожках, с передискретизацией 4×.

## 9. Форматы и этапы

VST3, AU, CLAP через clap-wrapper, плюс standalone для разработки. Инструмент, не эффект: принимает MIDI, не производит.

| Этап | Содержание | Оценка |
|---|---|---|
| 1 | Ядро синтеза как офлайн-функция: конфиг → wav с одним ударом | 1–2 недели |
| 2 | Каркас JUCE, MIDI, параметры, без интерфейса | 1 неделя |
| 3 | Настройка по слуху: диапазоны, кривые, характер сатурации | 1–2 недели |
| 4 | Интерфейс с окном формы волны | 2 недели |
| 5 | Пресеты, сборка форматов, проверка в хостах | 1 неделя |

Этап 3 — главный и единственный, который нельзя сократить. Всё остальное это программирование, а он — сведение. Доводить стоит на бочке и снейре, сравнивая с Microtonic и с живыми записями; когда эти два звучат хорошо, остальные получаются настройкой тех же ручек.

## 10. Открытые вопросы

- Нужен ли `Shape` отдельно от `Drive`, или одного насыщения на выходе достаточно. Проверить на слух прежде, чем закладывать оба.
- Хватит ли одного синуса для тела снейра или нужен второй осциллятор. По физике нужен, по экономии интерфейса — не хочется. Компромисс: режим осциллятора «dual», добавляющий второй синус на фиксированном интервале.
- Нужны ли pink и S&H шумы или белого с фильтром достаточно.
- Стоит ли рендерить окно формы волны в реальном времени или по отпусканию ручки.
